# LexCore AI documentation

This directory describes the application, local development environment, and contributor workflow.

## Reading order

1. [Project overview](PROJECT_OVERVIEW.md): understand the product, architecture, and implemented features.
2. [Setup and environment](SETUP_AND_ENVIRONMENT.md): install dependencies, configure services, and initialize a local database.
3. [Git workflow](GITFLOW.md): prepare a branch and submit a focused pull request.
4. [Commit standards](COMMIT_STANDARDS.md): write consistent, reviewable commit messages.

For a concise introduction, see the [project README](../README.md).

## Maintaining these guides

- Write documentation in English and use **LexCore AI** as the product name.
- Preserve actual Portuguese route names, schema identifiers, and interface labels in technical instructions.
- Update setup instructions when dependencies, environment variables, or service configuration change.
- Separate implemented behavior from proposed improvements.
- Use repository-relative links and commands that run from the repository root unless stated otherwise.
- Record checks honestly; do not describe a suggested check as a completed validation.
